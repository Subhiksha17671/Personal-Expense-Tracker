# 💰 Money Buddy – Personal Expense Tracker

### ✨ Your money, your rules!

Money Buddy is a colorful and user-friendly personal expense tracker built with HTML, CSS, and JavaScript. It helps users record daily expenses, manage budgets, understand spending habits, and track their money through interactive charts and summaries.

🌐 **Live Website:** https://Subhiksha17671.github.io/Personal-Expense-Tracker/

---

## 📸 About the Project

Money Buddy makes expense tracking simple, interactive, and fun! Users can record expenses, organize them by category, set spending limits, and view daily, weekly, and monthly summaries.

The application stores expenses and budgets in the browser using Local Storage, allowing saved information to remain available in the same browser.

---

## ✨ Features

- 🔐 **Demo Login Page** – A colorful login screen with username and password validation.
- ➕ **Add Expenses** – Record an expense with its name, amount, date, and category.
- 🗑️ **Delete Expenses** – Remove expenses that are no longer needed.
- 💰 **Total Expense Calculation** – View the total amount spent.
- ☀️ **Daily Summary** – Track today's spending, expense count, and highest expense.
- 📅 **Weekly Summary** – Review spending from Monday through Sunday.
- 🌙 **Monthly Summary** – Understand your monthly spending.
- 🎯 **Budget Manager** – Set daily, weekly, and monthly spending limits.
- ⚠️ **Budget Alerts** – Receive visual warnings when approaching or exceeding a budget.
- 🥧 **Interactive Charts** – Visualize category spending and weekly expenses.
- 🗂️ **Category Breakdown** – Organize spending into different categories.
- 🔍 **Search and Filters** – Search expenses by name and filter by category or date.
- 💾 **Local Storage** – Keep expenses and budgets saved in the browser.
- 📱 **Responsive Design** – Use the application on different screen sizes.
- 🚪 **Logout Option** – Return to the login page.

## 💾 Data Storage

Money Buddy uses browser Local Storage to save expenses and budgets.

- Data remains available in the same browser while its stored data is retained.
- Data does not automatically synchronize across different browsers or devices.
- Clearing browser storage may remove saved expenses and budgets.
- This project is intended for demonstration and learning purposes, not secure financial record storage.
